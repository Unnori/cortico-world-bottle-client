# 字体授权分类与压缩

用户授权：把本地字库分为可发布、有限制、未确认，转换明确许可的字体以减小包体；不发布。

## 分类标准与目录

“可发布”指允许随软件再分发及 WOFF2 无损封装，并仍须遵守 OFL 署名、附带许可等要求，不代表无版权或公共领域。9款：文楷等宽、悠哉、小赖、内海、清松1/2/8/9、随峰Plus。有限制2款：鸿雷、idfont。未确认4款：沐瑶软笔、平方时光、旧版清松1（JasonWriting1 1.016）、姚随心。未知不推定为侵权，也不以免费字体下载站代替作者授权。

- `world/fonts/redistributable`：允许默认加载/发布的全字符 WOFF2。
- `world/fonts/licenses`：每个字体完整 OFL、版权与来源清单。
- `font-library/redistributable/originals`：可发布原文件的本地备份。
- `font-library/restricted` 与 `font-library/unverified`：本地保留且不扫描、不进 NPM、不进 Git。各自附说明。总清单及来源证据在 docs/font-audit。

## 兼容与默认

字体清单分离物理文件和稳定名称：转换 WOFF2 保留原 filename 的映射键与资源 ID，不改部署字典。移出的字体保留映射但回退，不能偷偷抽新笔迹。目录根级仍支持用户自行导入。

鸿雷默认改成现已许可的霞鹜悠哉，共用可发布字库中的同一份 WOFF2，不重复占用包体；默认逻辑和自定义优先级不变。已导入个人字体的数据不改。

## 转换与验证

fontTools + Brotli 在工作区隔离环境执行，关闭 WOFF2 预处理变换与时间重算，保留字形、cmap 和所有 name 字段；逐表比较源与解压后的字节（仅容器校验和允许差异）。因此为纯压缩封装，不删字符、不改字体名称，符合 OFL FAQ 2.2.1 的条件。原文件备份并记录 SHA-256。

验证包含旧字典/ID兼容、隔离目录不扫描、所有 WOFF2 实际浏览器解析、默认和个人字体、局域网配对、离线打包清单无隔离原文件与受限字体、全量测试与类型检查。报告分别统计分类移除与压缩的效果。
