# 信笺字体与自定义外观

沿用信箱现有布局、潮蓝／暖纸／Coopanion 主题和明暗模式。外观菜单增加自定义主题色和背景图片；不用新区域打断读信。信件正文使用来信人的固定字体，标题与操作文字仍保持现有字体便于阅读。

- 将 E:/Download/fonts 的 9 个字体移入 world/fonts；按文件内容签名识别 TTF/OTF/WOFF/WOFF2，通过共用路由提供，远程口继续使用原配对鉴权。
- 来信人以已有匿名署名标识；种子信按署名隔离。映射以散列键保存于扩展数据 bottle-font-map.json；同一来信人的普通信和回信一致。每轮优先随机选使用最少的字体，使不同来信人尽量不同。新增字体动态加入，不修改任何已有映射；删除字体时旧映射保留、显示系统字体。只在字体目录 README 描述导入及停 World 后备份／移走字典重洗的方法，不在网页放重洗按钮。
- 自定义色基于一个主题色生成浅色与深色语义色板。保持文字与纸张对比，状态色沿用原语义色；卡片继续用同一个 appearance 入口取得配色。
- 上传背景为 PNG/JPEG/WebP，限 8 MiB；通过原有 x-bottle 防跨站请求机制与 LAN 配对访问。存于扩展数据目录，以摘要 URL 提供给其他设备。独立的上传入口允许较大请求，其余信件动作仍限制 4 KiB。内容验证，拒绝目录穿越与 SVG。
- 偏好统一写入原 bottle-appearance.json，其他设备打开同一信箱即复现。背景用纸色遮罩与不透明信纸保证可读，外观菜单可滚动适配小屏，遵守减少动画偏好。

验证：持久映射、新字体不重分配、资源路径、上传边界、旧偏好兼容、自定义明暗对比、真实浏览器字体加载和背景持久化、LAN 鉴权与现有回归。
