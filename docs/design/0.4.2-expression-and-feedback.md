# 0.4.2 表达自由、反馈便笺与自主延后修复

> 本设计已并入 0.5.0（2026-11-02）；下文的 0.4.2 与“不发布”为设计时的版本编号和阶段安排。

## 用户要求

正文只保留 120 字上限与人的身份/联系方式/本机私密信息边界；鼓励各种内容与文体。网页增加温柔的反馈入口，使用扩展同款图标；修复 no_idea 被误记为失败。仍不发布。

## 实现边界

- 同步修改 ENV_PROMPT、bottle_write 工具说明、人工写信/重写事件和随机邀请，不留下相反的文风限制。保留人工发送确认、外来文本隔离、正文授权、回信只写正文。
- 信题改可选，不因缺题挡住正文；填写时沿用既有服务端 1—20 字单行契约，不额外改服务端。正文不作情绪、题材、文体筛选。环境段仍保持 760 个非空白字符以内。
- 根因是写信邀请被模型用 action=remind, reason=no_idea 回应。每轮只有一份有效任务，no_idea/not_now 以当前已渲染或已投递任务为准，忽略模型误填动作。action 改可选；人的暂停/拒绝仍尊重显式 action，不擅自扩散暂停范围。没有投递任务时不接收无端 deferral，不接受仅排队尚未渲染的任务。晚到 settled 回调不复活已结算任务。
- 页脚入口使用群昵称「毛球」，不过度强调姓名/开发者身份。原生 dialog 展示 GitHub 与家长群两条路径，支持关闭、原生 Escape、点遮罩与焦点归还；不上传、自动提交、或代填私密内容。
- 同款 icon 使用本机只读精确资源路由 /icon.png（/favicon.ico 同源兼容），PNG 来自包内 world/icon.png。页眉和 favicon 共用，不遍历任意路径，不依赖外链。

仅修改扩展，不改宿主或实际安装目录；0.4.2 尚未发布。
