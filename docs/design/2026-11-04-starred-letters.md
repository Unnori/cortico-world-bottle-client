# 星笺匣与可撤回信件记忆

用户已确认采用不修改内核的独立信件记忆库；不直接读写 Persona/Memory 文件，不自动发布。

## 实施约定

1. 字号工具拖动后吸附最近的左右边缘，记住浏览器自身的位置；触摸、键盘、缩放与减少动态效果均可使用。
2. 星笺匣以 `letterId` 作为一次往来的去重键。寄出原信与收到的回信共享星标、记忆选择；定位优先回信。来客信与邮局信按同一规则使用。草稿尚未寄出，不进入往来收藏。
3. `bottle-stars.json` 单独持久化星标与记忆授权；正文仍保留于现有信册，只有有效授权的信件组成独立记忆池。不重复写一份失控的正文副本，不改变珍藏或服务器信件状态。
4. 总开关默认关闭，星标本身不授权读信；总开关开启且逐封勾选才允许完整正文作为 external 延迟事件进入上下文，并可由只读工具后续重读。禁止将正文放入环境/system 前缀或工具声明。待投递事件在渲染时再次核验授权，关闭、取消星标、删除信件、重启均使旧队列失效。
5. 关闭逐封授权或取消星标立即从可读池移除；关闭总开关清空全部逐封授权，重新开启不能复活旧授权。已投递正文、既有上下文或摘要不能追回，此限制在网页明确说明。普通人工「回信／一起读信」仍是独立授权，不受星标设置代替或禁止。
6. 网页记忆文案代入实际桌宠名；World 配置与扩展页使用通用称呼。路由共用现有本机／LAN 配对与防跨站机制，只接受 ID 和严格布尔值，不接受客户端提供的正文。

## 信箱视觉统一调整

星笺列表沿用现有 `.mail` 的纸色、10px 圆角、细边框与悬停效果，配同款信封图标和宋体信题；界面正文仍使用页面无衬线字体。色彩继承当前主题 `--card/--panel/--ink/--muted/--line`，仅选中星星保留金色（浅色 #ac780b，深色 #efc35d）。星标按钮使用透明底，避免金框抢占信件状态的注意力。

记忆总开关以信册内说明行呈现，逐封授权放在每条信封底部，保持醒目且不重复嵌套卡片。复杂说明折叠到「关于信件与记忆」，关闭状态与授权用途始终可见。手机上缩短图标按钮但保留 44px 点击范围；沿用主题过渡与减少动态效果设置。

## 验证执行

先覆盖存储去重、重启、关闭总开关、单封撤回、延迟事件取消、模型伪造读取与独立读信授权；再验证页面联动、跳转、拖动、所有主题与手机布局，最后运行全量测试、类型检查和自描述检查。浏览器验证使用隔离假信箱，不读取真实信件。
