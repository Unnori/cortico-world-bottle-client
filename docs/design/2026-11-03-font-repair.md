# 失效字体绑定修复与慢速下载

已确认采用：仅修复旧字典里已从当前字库清单撤下的字体，正常绑定与停用但仍存在的字体保持不变。当前浏览器通过信箱 GET 请求头报告最多 32 个已缓存的字体内容摘要，本机 World 与当前启用清单取交集后补选；无可用缓存时从启用字库补选。结果写回原字典，其他设备沿用。浏览器存储不可用时使用正常请求，不阻止信件显示。缓存内容损坏仍由原有字体长度/头/摘要验证拒绝。

将独立网页字体文件下载超时由 20 秒改为 180 秒；保留失败后稍后重试、系统字体兜底，不修改清单刷新间隔、不向字库站发送任何信件信息。无需改中央服务端或 Coopanion 内核，不自动发布或重启真实 World。

验收：失效绑定补选并落盘，重启及另一设备读取稳定；有效/停用绑定不变；无缓存、未知摘要、空池、存储异常处理；真实 HTTP 的缓存摘要传递与 LAN 鉴权；用真实浏览器验证已缓存字体补选、网络断开重载与超过 20 秒的慢字体加载。
