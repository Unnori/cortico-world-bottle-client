# 1.0.0（待发布）：回信状态与桌面通知

本地筹备，暂不提交或发布。用户已确认以下行为。

- 原信没有共读、也没有寄出回信时，显示「尚未共读」。真正寄出回信后显示「已回信」；共读次数大于零时另显示「共读 X 次」。起草不算寄出，回信不虚增共读次数；旧信册无需迁移。
- 新桌面通知位于最下方，旧通知上移。同一封原信的阅读等待、回信草稿使用同一个通知标识，更新保留原位置；不同信件互不覆盖。桌面放不下的较早通知暂时隐藏，仍可在信箱查看；通知关闭不删除信册。
- 等待回调必须仍属于当前 World、当前信、当前授权，且尚未产生草稿。寄出、结束轮次、授权丢弃、换信或停止后，旧等待回调失效。
- 一个隐藏 PowerShell 宿主管理多个 WPF 卡片；复用现有卡片外观、声音和完整预览。原生按钮绑定所展示的信件，草稿按钮继续绑定准确 ID/版本。
- 同一通知更新不改变顺序，关闭回执绑定通知版本。关闭/停止清理临时正文，排序元数据仅限本次运行。最多保留 20 张通知，超出部分只在信箱中查看。

验证覆盖实际信册渲染、共读独立计数、等待竞争、通知顺序/更新/关闭、旧卡片操作隔离、PowerShell 语法与隔离宿主运行。不改服务器、Bridge 协议或正在运行的桌宠。
