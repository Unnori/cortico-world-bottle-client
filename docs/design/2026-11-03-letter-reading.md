# 信件正文阅读调整

本次按用户明确的阅读需求调整独立信箱网页，不改内核与 World 配置页，不发布。

- 种子信待处理卡片、珍藏记录的落款使用同一封信 fontId；保留作者字典，不重洗字体。
- 所有 .letter 正文统一默认 26px（原正文 19px、归档 16px、窄屏 17px），1.85 倍行距；最大阅读宽度 680px，居中，保留换行并允许长词折行。落款右对齐并跟随字号。页面、列表、正文标题与按钮不跟随字号缩放。
- 左侧悬浮「Aa 字号」展开调节面板，滑条 18–40px，input 事件直接更新独立 CSS 变量。默认按钮恢复 26px。窄屏控件固定左下角，面板向上展开；外侧点击或 Escape 收起，Escape 恢复焦点。使用现有动画助手并尊重减少动态效果。
- 字号只写当前浏览器 localStorage，便于手机和桌面分别设置，不混入跨端信箱主题。读入旧值时处理非法值与上下限。
- 使用合成数据测试种子信真实字体、落款、即时缩放与持久化，覆盖 1320/390/320 宽度、四主题明暗模式；保持现有正文布局回归与全量测试。

后续按用户要求更新：信内标题改为随正文 1.16 倍缩放，正文加入独立信笺容器。详见 2026-11-03-letter-stationery.md；此前“信件标题不跟随”的决定已被替代。
