# 外观面板第二轮调整

保留现有信箱的信纸和配色，不重排读信区。外观下拉内按配色、明暗、个性化三层排列；个性化以分隔线区分主题色、背景、我的字体，替换原生裸露文件输入，增加缩略图和字体预览。手机面板限制高度并滚动。

- 按钮的 accent/seal/sea 精确使用选中色，明暗只改变纸张与墨色；另设 accent-text 供小字与描边色语义使用，按钮根据原色选黑／白字。
- 背景透明度 0–100%，默认 82% 延续原视觉。仅有背景时展开滑条，拖动实时预览，松手保存。双图层加载后交叉淡入，减少动态效果时直接切换。
- 来信字体只应用正文与正文中的实际信件标题，不触碰列表折叠标题、页面标题、状态标题。
- 我的字体单独上传到部署数据 bottle-my-fonts，以内容摘要寻址，最大 32 MiB；不进入随机字体池，不改变发送内容。保存 myFont/myFontName，覆盖本机信箱的 Coo 草稿、寄出记录、回信与引用原文。已配对设备读取同一本机信箱也可加载。入口明确注明“仅在本地信箱生效，不会影响收件人的展示”。
- 偏好兼容旧记录，删除／恢复默认均显式处理；原普通操作请求体限制和 LAN 配对边界不变。

验证真实配色像素／计算样式、极端主题色文字对比、滑条显示与保存、字体边界及实际加载、只覆盖正文标题、跨端恢复与动画降级。

- 真实文件输入上传背景与个人字体；透明度松手保存、刷新恢复、删除后收起，以及配对 LAN 独立 origin 恢复均通过。
- 检查来信内标题／正文的同一字体，Coo 草稿／历史／回信引用的个人字体覆盖，列表标题与页面标题仍保持原字体。
