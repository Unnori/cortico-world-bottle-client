## 展开通信与小纸条修正

- 成因：attachPapers 每轮拆下纸条、停放再插回，重播 CSS 入场；与书信无关的额度/邀请更新也重建整册。
- 固定节点：仅目标容器变化时移动；书信内容、分类、星笺数据未变则复用现有信册。草稿首次抵达滚动一次，重写只替换内容，不再抢焦点；返回页面恢复正文。
- 布局：展开后透明外底 + 统一内边距，回信与原信纸同宽；信件操作栏仅共读/删除；下方独立纸条区承接邀请/草稿/收件便签。草稿出现时隐藏重复邀请，保留纸条随往来附着的语义。
- 沿用现有主题 tokens、信件字体与字号。仅减轻阴影、收紧大空白，不修改正文、署名、寄送权限、服务端或存储格式。
