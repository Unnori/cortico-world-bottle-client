# 本地写信默认字体

用户指定鸿雷小纸条青春体作为默认写信笔迹，同时要求它不参与来信随机池、导入字体优先、右上角显示当前笔迹。

- 字体和随附使用声明复制到 world/default-fonts。独立 descriptor 保留名称与内容 SHA-256，沿用 /my-font/<摘要>.ttf 路由，受原 LAN 配对保护。
- myFont 为 null/未设置时前端选择内置字体；用户已有选择优先。恢复默认清除自定义选择，回到内置字体，不写入或重洗字体字典。
- 外观菜单增加始终可见的当前笔迹行，自定义上传区域保留字体名和实际字体预览。字体仅影响 Coo 本地正文/标题/落款，不影响来信或寄信负载。
- 字体池自动扫描有效文件，不写死数量。此次本机实查随机池为14个，新增默认字体独立于池外。
- 验证内容摘要、字体池隔离、未配对拒绝/配对读取、真实默认字体解析、上传覆盖、重载保留、恢复默认与包内文件清单。仅本地修改，不发布、不重启桌宠。

验证结果：553 项测试通过；实际浏览器成功解析14个随机字体和默认字体，验证导入覆盖、刷新保留、恢复默认与配对手机加载。离线打包预览确认14个随机字体、独立默认字体和原使用声明均会包含，未生成发布或执行发布。
