# 信纸多图排版（0.9.0）

用户选择：若复杂效果需要改中央服务器，则一次实现完整链路。现有服务器仅校验 v1，会丢弃额外布局字段，因此升级两端；不部署线上、不重启桌宠、不改信箱操作和设置页布局。

v1 原样读取和显示。v2 支持最多八幅内置/静态 SVG 图，每幅独立颜色、百分比中心坐标、纸宽百分比图框、旋转、透明度、镜像、前后图层和层内顺序；四角/中心与大小预设供简单用法。自创图单幅 8 KiB、合计 16 KiB，排版线格式 32 KiB，仍受既有 40 KiB 请求体限制。所有数值有界，SVG 白名单不放宽。未知字段不转发，非法图案拒绝起草/发送，收信时仅去掉装饰并保留正文。

新草稿内置图案缺色时由本机身份派生稳定画笔色并固化到草稿；只发送颜色，不发送身份。桌宠可逐封覆盖。自创 SVG 默认保留原色，显式换色时保留透明、留白、内部渐变和裁剪引用。历史信件不改色。纸色可选，墨色按纸色调整对比度。

排版全部存入草稿版本和信件，预览、确认、收信、回信、信册、导入导出、重投使用同一份数据。纸内独立后景/前景层，前景整体透明度额外限制为 .35；装饰不捕获输入、无法移出纸面，正文与按钮结构不变。这里不增加拖拽编辑器。

新服务器继续声明 stationery:1，另声明 stationery_layout:2。新客户端遇到旧 v1 海边时显式降级为第一幅角落图（尽量嵌入换色后的 SVG）；完全不支持装饰则寄正文。本机保留完整排版，并如实提示。旧客户端无法理解 v2 时保留正文，装饰需升级客户端后显示。

验证涵盖边界/恶意参数、换色与透明/留白、两端真实业务往返、旧能力降级、版本确认、重启、导入导出、服务端不落盘和备份过滤，以及窄屏/明暗模式下的纸内图层与正文可读性。客户端与独立服务器分别检查、打包，线上生效需要另行部署两端。
