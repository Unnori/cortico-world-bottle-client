# 1.0.0 中文提示词与上下文开销

2026-11-16。本次对比基线为修改前的本地 1.0.0 筹备版，不把它冒充已发布的 0.9.3。

## 这次改动

- 信箱顶栏把「使用小册」「海边碎碎念」与反馈并列，保持低调；使用带斜杠的 `https://bottle.sqnori.com/guide/` 和 `https://bottle.sqnori.com/notes/`，点击后在新页打开，不自动请求站点。
- 16 个工具及其参数说明统一简洁中文，保留原工具名、参数键、枚举、必填和数值限制；共同规则集中在环境段。
- 邀请、自动读信、共读、纸条、寄出、归还、被捡起、回信、系统信和星笺事件均改为中文；正文、署名、信题和控制端自报来源保持原样。
- 邀请明确允许跳过，不为额度凑字；定时邀请和待办仍为 piggyback，手动邀请等明确请求仍为 flush，到信仍合并。实际授权、版本检查、发送确认、拒绝/暂停和投递间隔不变。

## 怎么估算

只计算漂流瓶自身，使用 Cortico 自带 `estimateTokens`：汉字、指定全角标点等每字符 0.6，其余码点每字符 0.3，整体向上取整。工具按 Responses 风格 `{type,name,description,parameters}` 的紧凑 JSON 统计，环境段用合成空信箱状态实际展开占位符；不读取真实聊天和信件。

这是宿主界面与预算估算所用的近似口径，**不是指定模型的分词结果或账单**。不同模型、Chat/Responses 协议包装、宿主事件来源/时间/外部文字框架、其他扩展、历史消息和缓存计价都会影响实际数字。本次没有调用收费模型来测账单，也不把中文字符减少比例直接当成真实 Token 减少比例。

## 固定输入

| 内容 | 修改前估算 Token | 修改后估算 Token |
| --- | ---: | ---: |
| 16 个工具完整声明（含 JSON 参数结构） | 8,218 | 4,779 |
| 展开后的环境提示词 | 436 | 343 |
| 两者连同分隔换行一起估算 | **8,654** | **5,121** |

固定部分减少约 **41%**，约 **3,530 Token**。逐项取整与合并取整有 1 Token 左右差异。完整携带这些内容的 100 次模型请求，单这一部分的估算输入从约 86.5 万降到 51.2 万；实际费用还要看模型价格、历史和缓存命中。

工具表仍是主要开销。其中去掉所有 description 后，单纯参数键、类型、枚举和 JSON 结构就约 **2,440 Token**。`bottle_write`、`bottle_reply`、`bottle_rewrite_draft` 都需要兼容完整信纸排版，三者约占工具表的四分之三。装饰字段即使未使用，工具声明也仍需传递。本轮不通过改参数格式或删能力来压缩这部分。

聊天处理关闭时，相关工具也固定注册，调用时实时拒绝；这是为兼容宿主会话工具缓存、避免热开启后缺工具。不能靠随开关删减工具表来省输入。

## 按需进入的事件

事件目录共有 **18 种**。目录的说明给人查看，不整表注入模型；只有实际投递的事件文字进入上下文。

以下为可复现合成状态下的事件正文估算，不包含宿主包装：

| 单次事件样例 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 写信邀请（无历史读信） | 110 | 72 |
| 打捞邀请（无历史打捞） | 91 | 68 |
| 待办提醒 | 68 | 32 |
| 自动捞信阅读，含 7 字合成原文 | 187 | 93 |

邀请会按事实加入上次打捞或已授权阅读的时间、署名/信题，状态不同字数也不同。延迟通知的时间始终绑定原信寄出时间，不把检测时间当成被捡起或回信到达时间。

完整 120 字中文正文单独约 72 Token；40 字纸条约 24 Token。共读原信、回信和纸条会叠加对应正文，批量来信还会按数量增长。装饰参数也可能增加开销；事件里的自创 SVG 用未渲染占位说明，不把源码当作已经看见的图像。

piggyback 可以减少单独唤起模型的次数，但事件被带入后仍占上下文；留在后续历史中的内容也不会因此变成免费。
