# R2 字库上传准备

用户已选择 R2 + 静态清单，域名为 `https://fontsforletters.sqnori.com/`，本轮要求整理所有上传文件、说明新增字体与拖拽上传方式。

生成器从已审核的9款 WOFF2 与完整许可初始化本地管理目录 `font-library/cloudflare-r2/source`，`library.json` 保存稳定原文件名、标签、来源、许可及启用状态。可上传产物仅在 `upload`：内容摘要命名的字体与许可证、授权索引和 `catalog.json`。清单保留旧名称派生的 ID 和默认字体 ID，URL 固定使用给定 HTTPS 域名。先验证全部输入，再写不可变对象，最后原子替换清单；再次生成不删旧字体，避免旧链接失效。

配置、CORS、缓存元数据与管理说明在 upload 外，防止误当 R2 对象元数据。R2 控制台不会自动读取这些本地配置。增加字体需来源文件 + 完整许可 + library 记录，再生成、先上传资源、最后上传清单；停用使用 enabled=false，保留旧记录和对象。

本轮仅准备本地资源，不上传、不发布、不修改实际字体加载、不搬空正在使用的运行时字体。客户端迁移与浏览器缓存验证留待资源就绪后完成。验证包含实际9款资产哈希、稳定 ID、缺少许可/重复 ID/文件变化拒绝、更新清单保留旧对象，以及生成可复现性。

## 后续迁移与打包准备

用户要求将完整管理目录移至工作区根，并清空扩展内字库准备打包。现管理目录为 `E:\WorkShop\Coopanion_DevelopMod\bottle-font-library`，运行时仅保留清单元数据与许可副本。

RemoteFontCatalog 在页面刷新时后台检查清单，去重、5分钟有效期、失败1分钟退避、5秒超时、512KiB上限，验证稳定 ID/域名/尺寸/OFL。缓存有效元数据到部署目录，离线可使用包内元数据。字体流量不经过宿主，浏览器按资源摘要存 IndexedDB（兼容 HTTP LAN），原生解析通过后才写缓存；存储失败直接联网，远端失败显示系统字体。个人导入仍本地优先，旧字典和停用字体保留。
