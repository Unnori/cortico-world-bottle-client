# 信箱页面重排与三套主题

> 本设计已并入 0.5.0（2026-11-02）；下文的 0.4.2 与“不发布”为设计时的版本编号和阶段安排。

默认从扩展 Icon 取靛蓝、浅海蓝、奶白色，保留信纸、邮戳、蜡封和按来信分类的信册。页面上部改为左侧信箱题记、右侧行动台，下面依次是邀请设置、待办与信册；移动端自然单列。

右上角提供潮蓝、暖纸（原色彩）、Coopanion 三套配色，使用同一套布局与语义颜色。每套都有浅色、深色版本，明暗默认跟随系统，或可手动选择。配色和明暗偏好保存在本机浏览器 localStorage，支持跨标签同步；首屏在 CSS 前设置颜色，避免先闪出浅色。菜单支持键盘、Escape、点外部关闭。

Coopanion 同步沿用 `Cortico/src/web/shared/theme.ts` 的原生主题规范与内置色板；从 `WorldContext.botDir` 只读 `theme.json` 以及部署默认 `config.json:web.theme`。这与公开 `GET /api/theme` 使用同一数据源，不需要猜宿主端口、跨端口登录或访问私有内核。支持内置方案与自定义方案，缺项、失效的方案按宿主规则回退。不写宿主主题，不改变全局明暗。

独立页面 `GET /theme` 只返回经过校验的颜色白名单和方案类别，隐藏自定义名称、说明和其他配置。首次 HTML 携带同一份快照；选中 Coopanion 且页面可见时约每 5 秒检查变化。临时读取失败保留最近颜色；旧宿主缺少主题模块或首次不可用时回退潮蓝，并在菜单说明。JSON 快照转义小于号，颜色限定为十六进制，不能注入脚本或外部资源。

交互动画只响应行为：主题颜色渐变、主体切换、分类切换、信件/设置展开收起、反馈弹窗打开关闭。折叠动画保留展开记忆，快速反复点击可取消并续接，后台页通过动画完成 Promise 收尾；减少动态效果偏好下立即切换，不能因为动画阻断操作或重复请求。轮询不会反复播放整页动画。

不更改写信/打捞/寄出权限、额度、暂停、草稿或回信逻辑；不使用远程字体、额外图床或新的前端依赖。沿用本地 0.4.2，不发布。
