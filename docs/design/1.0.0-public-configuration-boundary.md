# 1.0.0 待发布：宿主配色快照与固定伙伴称呼

## 三段单向配色链路

1. 面板点「打开信箱」前，在同源浏览器读取 `/api/theme` 的方案标识与模式，用 getComputedStyle 采集 14 个白名单 CSS 色值，只接受六位十六进制颜色。只观察当前界面，不读取主题名称、说明、其他 World 配置或部署主题文件。
2. 通过 `ctx.invoke('hostTheme', [snapshot])` 递给 World，校验形状后原子保存到 `<dataDir>/bottle-host-theme.json`。记录 selectedId、appearance、palette、浏览器 at、World observedAt 和 hostVersion。公开响应没有版本时写 unknown，不能为补齐版本而读取宿主 package/config。
3. 保存成功后打开信箱。页面刷新由服务器注入 `<script id="host-theme">` 和映射后的配色；本机 GET /host-theme 可读取快照。pref.theme=host 时覆盖自有配色，缺键用内置值；完全没有快照则回退潮蓝。关闭面板或宿主接口不可用，不影响独立信箱继续使用最后有效快照。

面板显示「当前跟随：mint」等摘要。不会将快照发到中央服务器，不导入 cortico/web/shared/theme.ts，不访问宿主 config.json:web.theme 或 theme.json。旧 coopanion 选项仍兼容为 ocean，字体、背景与自定义色保留。

## 明暗与失败处理

- 当前快照只记录实际观察到的一种明暗；host 主题沿用它，不把一份浅色配色冒充深色。选择其他主题后可继续自由切换明暗。
- 非法色值、损坏快照和读取失败不能注入脚本或 URL；缺色由内置色板补齐。采集或保存失败时仍可打开信箱，保留旧快照；没有旧快照就使用潮蓝。
- 为避免异步采集丢失浏览器点击授权，先预留空白窗口，保存后才导航到已校验的信箱根地址；面板卸载时关闭预留窗口。
- 文件只保存最后一次快照，无正文和身份信息。它属于外观偏好，清空信册不会删除；后续采集覆盖，删除本扩展数据目录时一并删除。
