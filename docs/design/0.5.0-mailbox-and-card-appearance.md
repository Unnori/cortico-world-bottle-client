# 0.5.0 信箱与桌面卡片外观

将原定 0.4.2 的工作整合为 0.5.0 大更新，发布日期为 2026-11-02。

网页正文和标题明确使用语义文字颜色，避免浏览器附加样式中的通用 body、标题、按钮规则覆盖深色文字。外观面板使用三张预览卡，选色后保留面板，方便继续选择明暗。指代桌宠的页面文案使用当前名字，指代信件的“它”保留。

内置主题语义颜色放在 appearance.ts，网页 CSS 与原生卡片共用。主题及明暗选择经现有 x-bottle 请求保护的 POST /appearance 保存到扩展数据目录的 bottle-appearance.json；不改宿主配置。页面首次打开兼容原浏览器偏好，已有部署记录时优先恢复，连续选择按序保存。

原生卡片启动时读取本地 GET /appearance，使用独立浅深色板；显示期间通过异步本地请求同步变化。system 模式读取 Windows AppsUseLightTheme。共享 WPF 画刷执行颜色过渡，关闭窗口停止定时器和请求。离线启动使用随卡片数据附带的本地主题回退。主题请求不包含信件、不发送 World 事件，不改变卡片按钮行为。

验证：页面事件、偏好持久化与恢复、接口校验和请求保护、真实浏览器附加样式下的文字颜色、窄屏菜单、原生 WPF 离屏渲染与实时换色。

验证记录：421 项测试通过，扩展与 Web 面板类型检查通过。真实 Edge 保留附加样式并追加通用黑字规则，六套主题/明暗组合的正文、标题和主体按钮颜色正确；320、390、768 像素下菜单不溢出，选择保存与重新打开恢复通过。直接执行原生脚本的配色函数，六套 WPF 画刷切换和无效色板保留测试通过。

验证限制：自动审批阻止启动原生卡片离屏预览进程，仅返回 blocked by policy。未运行完整 WPF 窗口，因此不将原生窗口的最终渲染与显示期间自动换色记为实机通过。

## 发布前复核（2026-11-02）

436 项测试、扩展与 Web 类型检查、框架 describe/check 均通过。独立浏览器回归覆盖电脑与 390px 窄屏下的三套浅深色主题、信件正文与引用留白、长链接换行，以及错误提示淡出配色；用户打捞的瓶子安静归还、桌宠打捞仍通知与重启持久化均有回归用例。原生窗口实机验收限制仍如上，不把自动测试等同于完整窗口验收。
