# 提示音包

## 文件放在哪里

```text
world/sounds/
├─ 通用音效.wav                   # 根目录文件：来信、回信都可选
├─ incoming/                    # 来信专用，只显示在来信音效列表
│  └─ New_notifications_1.wav   # 默认来信提示音
├─ reply/                       # 回信专用，只显示在回信音效列表
│  └─ New_notifications_3.wav   # 默认回信提示音
└─ README.md
```

**只有直接放在 `incoming/`、`reply/` 两个子目录同级（即 `world/sounds/` 根目录）的音频，才同时出现在来信和回信列表中，并标记「通用」。** 文件只扫描上述三处的直接文件，不递归扫描更深层目录，也不扫描其他自建子目录。

即使两个子目录里存在同名文件，它们也是不同选项：来信只使用 `incoming/文件名`，回信只使用 `reply/文件名`，不会混用。此规则同时适用于 World 配置页与网页信箱。

## 添加与选择

可添加 WAV、MP3、M4A、OGG、AAC 或 FLAC 文件，单文件不超过 10MB；文件名（去掉扩展名）就是列表显示名称。来信默认 `incoming/incoming_default.wav`，回信默认 `reply/reply_default.wav`。其余已有音效仍可自行选择，不会因修改默认值而覆盖。

World 配置页的下拉选项每次打开时重新扫描；网页信箱刷新后重新加载。来源选择 `pack` 使用包内音效，`local` 使用单独选择的本机文件，`off` 静音。音量与末尾淡出可调整。旧版本内置 `default.wav` 选择会更新为对应新默认值；网页曾误选另一目录或已删除的音效时，会回到本类默认音效，有效的自选、静音与本机文件选择保留。

Windows 建议 WAV/MP3，其他格式能否播放取决于系统解码器；浏览器格式支持也因设备而异。不支持指向包目录外的符号链接。

安装包升级可能覆盖包目录，自己的音效请另行备份，也可以在设置中选择外部本机文件。网页选择的本机文件保存在该浏览器的 IndexedDB，不上传到电脑或服务器，也不影响其他设备。
