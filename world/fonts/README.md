# 信箱笔迹与远程字库

内置笔迹现在从 `https://fontsforletters.sqnori.com/` 加载，本目录只保留清单、版权/许可说明，不包含 TTF、OTF、WOFF 或 WOFF2 二进制。`catalog.json` 是离线启动时的元数据兜底，宿主每5分钟最多检查一次云端清单；失败保留有效清单，1分钟后才允许重试。字体文件由各自浏览器直接下载，宿主不下载整套字库。

## 字体绑定

每位发信人（种子信按署名）固定一种笔迹，字典位于部署数据 `bottle-font-map.json`。云端清单里启用的字体参与新绑定，停用字体仍可用于已有绑定。增加字体不重洗已有信件，字体资源 ID 继续由原始文件名派生。旧映射若指向已撤下字体则使用系统字体，字典值保留，不偷偷换笔迹。

## 浏览器缓存与多端

每个浏览器按字体摘要 URL 将字节缓存在 IndexedDB 的 `bottle-letter-fonts` 数据库，可兼容 HTTP 局域网信箱。下次阅读先查缓存，缓存被清理后重新下载。读取失败、浏览器禁用存储或空间不足时仍可直接联网加载；字体加载失败时正文用系统字体显示。支持 Web Crypto 的环境会验证摘要，所有环境校验字体头与长度，浏览器本身再解析字体。

清单与字体地址仅允许指定的 HTTPS 字库域名；不向 R2 发送正文、署名、配对 cookie 或令牌。各设备共享同一宿主的绑定字典，分别保存字体缓存。

## 自定义我的字体

网页「信箱外观 → 个性化信箱 → 自定义我的字体」仍支持上传自己的 TTF/OTF/WOFF/WOFF2。文件独立存于部署数据 `bottle-my-fonts`，只改变 Coo 本地正文、信内标题和落款，不进入来信随机池，也不随信寄出。已配对设备通过本机受保护路由读取。默认写信笔迹为云端清单指定的字体，当前是霞鹜悠哉。

本目录保留但不再扫描本地文件来扩展默认随机池；不要把整套字库重新放回包中。

## 主动重洗（高阶操作）

日常增添字体无需重洗。确需重新随机时，停止 World，备份并移走部署数据内的 `bottle-font-map.json`，再启动 World，下次阅读时重新绑定；旧信笔迹也会改变。网页不提供此按钮，不分享部署字典。
